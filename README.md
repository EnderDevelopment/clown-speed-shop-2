# Clown Shop Speed Boost

Clown Shop Speed Boost is a Roblox script that allows players to purchase a temporary speed boost from a clown shop NPC. This script enhances the player's movement speed by 2x for 30 seconds, providing a fun and engaging experience for Roblox game developers and players.

## Install

1. Download the `ClownShopNPCScript.server.lua` and `PlayerSpeedBoostScript.client.lua` files from the GitHub repository.
2. In Roblox Studio, navigate to the `ServerScriptService` and create a new Script. Name it `ClownShopNPCScript` and paste the contents of `ClownShopNPCScript.server.lua` into it.
3. Navigate to the `StarterPlayerScripts` and create a new LocalScript. Name it `PlayerSpeedBoostScript` and paste the contents of `PlayerSpeedBoostScript.client.lua` into it.
4. Create a clown shop NPC in your game and connect it to the `ClownShopNPCScript.server.lua`.

## Use

1. Players can interact with the clown shop NPC to purchase the speed boost.
2. Upon purchase, the player's movement speed will be increased by 2x for 30 seconds.
3. The speed boost will automatically deactivate after 30 seconds.
